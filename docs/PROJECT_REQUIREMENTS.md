# 浙江技能升学择校平台项目需求

## 1. Executive Summary

### Problem Statement

浙江初中毕业生中，成绩处于普高边缘或未被普高录取的学生家庭，在了解技工院校尤其民办技工学校时，面临信息分散、口径复杂、官方文件难读、学校宣传难辨真伪的问题。现有公开渠道更偏监管或招生公告，不足以支撑家长做横向比较和风险判断。

### Proposed Solution

建设一个面向家长的第三方 Web 择校信息平台，先聚焦浙江省技工院校库，整理学校档案、招生计划、专业方向、费用、来源核验和避坑内容，帮助家长“看懂、比较、核验”技能升学路径。

### Success Criteria

- MVP 收录浙江约 97 所技工院校基础档案，学校覆盖率达到 95% 以上。
- 每所学校至少包含：名称、所在地、办学性质、公办/民办、主管部门、专业、招生计划来源、联系方式、来源更新时间。
- 关键字段来源标注率达到 90% 以上。
- 家长能在 3 次点击内完成“按城市找学校”“按专业找学校”“查看学校详情”。
- MVP 至少上线 10 篇解释型内容，覆盖技校/职高区别、民办技校风险、预备技师、热门专业风险等主题。

## 2. User Experience & Functionality

### User Personas

- 中考后未被普高录取或处于普高边缘的学生家长。
- 想了解技工院校、民办技校、技能升学路径的初中毕业生家庭。
- 需要核验学校招生信息、费用、专业真实性的择校咨询人员或班主任。
- 希望展示学校信息但不直接控制平台核心资质数据的技工院校招生老师。

### Core Positioning

平台定位为：**第三方技能升学择校信息与决策辅助平台**。

必须避免使用容易误导的名称和文案，例如“官方招生平台”“浙江省技工招生平台”“阳光招生平台”。推荐命名方向：

- 浙江技能升学择校参考
- 浙江中职技工择校助手
- 初中后技能教育择校指南
- 技能教育地图

首页和学校详情页必须展示免责声明：

> 本平台为第三方信息整理与择校参考工具，非政府招生录取平台。报名、录取、学籍注册以教育、人社部门及学校官方公告为准。

### User Stories

- As a 家长, I want to 按城市筛选技工院校 so that 我能先看到孩子可就近选择的学校。
- As a 家长, I want to 按专业方向筛选学校 so that 我能知道哪些学校开设孩子感兴趣的专业。
- As a 家长, I want to 查看学校详情和信息来源 so that 我能判断学校是否可信、信息是否可核验。
- As a 家长, I want to 对比公办和民办学校 so that 我能理解费用、管理、升学和风险差异。
- As a 家长, I want to 阅读技能升学路径解释 so that 我能理解三年制中技、五年高级工、预备技师等路径的区别。
- As a 平台运营者, I want to 为每条核心数据维护来源和更新时间 so that 平台可信度来自可追溯信息，而不是主观背书。

### Acceptance Criteria

- 首页提供三个主入口：按城市找学校、按专业找方向、按升学/就业路径了解。
- 学校列表支持城市、学校性质、公办/民办、专业方向、学制/层次筛选。
- 学校详情页展示基础信息、招生专业、费用说明、官方来源、风险提示、核验入口。
- 每个学校详情页必须标注数据来源状态：`已官方核验`、`来自学校公开信息`、`待核验`。
- 内容文章必须使用家长能理解的语言，不使用招生宣传式承诺。
- 平台不提供报名、录取承诺、就业承诺、代收费功能。

### Non-Goals

- 不做政府招生录取入口。
- 不承诺录取、升学、就业。
- 不替学校收取报名费、定金或学费。
- 不按报名成功向学校收费。
- MVP 不覆盖全国，不优先覆盖普通高中。
- MVP 不做完整 CRM、招生线索分发或复杂学校后台。

## 3. Technical Specifications

### Architecture Overview

第一版为 Web 平台，采用“结构化数据 + 内容管理 + 查询筛选”的轻量架构。

核心模块：

- 学校库：维护浙江技工院校基础档案。
- 专业库：维护专业分类、专业解释、适合人群、升学/就业方向。
- 招生计划库：按年份维护专业、层次、学制、计划人数、来源文件。
- 来源核验系统：为学校、专业、收费、计划等字段绑定来源链接、更新时间和可信状态。
- 内容中心：发布家长解释型文章。
- 前台检索：支持城市、专业、学校性质、公办/民办、费用区间筛选。

### Data Interfaces / Types

至少需要以下核心数据结构：

#### `School`

- `id`
- `name`
- `city`
- `district`
- `schoolNature`
- `ownership`: 公办 / 民办 / 待核验
- `supervisingDepartment`
- `address`
- `phone`
- `website`
- `officialAccount`
- `sourceStatus`
- `lastVerifiedAt`

#### `Program`

- `id`
- `schoolId`
- `name`
- `category`
- `level`: 中技 / 高级工 / 预备技师 / 其他
- `duration`
- `planYear`
- `planCount`
- `tuition`
- `sourceStatus`
- `sourceUrl`

#### `Source`

- `id`
- `targetType`: school / program / fee / article
- `targetId`
- `sourceName`
- `sourceUrl`
- `sourceType`: 官方文件 / 学校官网 / 招生简章 / 公众号 / 待核验
- `verifiedAt`

#### `Article`

- `id`
- `title`
- `category`
- `summary`
- `content`
- `publishedAt`
- `updatedAt`

### Key Pages

#### 首页

- 平台定位说明。
- 按城市找学校。
- 按专业找方向。
- 技能升学路径入口。
- 热门解释文章入口。

#### 学校列表页

- 筛选：城市、性质、公办/民办、专业、学制层次。
- 排序默认按地区和匹配度，不按商业付费排序。
- 每张学校卡片显示名称、城市、公办/民办、开设方向、来源状态。

#### 学校详情页

- 基本信息。
- 官方来源与核验状态。
- 招生专业与计划。
- 费用说明。
- 适合人群。
- 风险提示。
- “我要核验”来源链接区。

#### 专业详情页

- 学什么。
- 适合什么学生。
- 对应岗位。
- 升学方向。
- 常见宣传风险。
- 开设该专业的学校列表。

#### 内容中心

- 技工学校 vs 职高。
- 民办技校怎么看。
- 预备技师是什么。
- 五年高级工是什么。
- 护理、幼教、电商、新能源汽车等热门专业风险解释。

### Security & Privacy

- MVP 不采集学生身份证、准考证号、成绩单等敏感信息。
- 如后续提供咨询表单，仅采集最小必要信息，并明确用途。
- 不出售学生线索。
- 学校认领页面后，不能自行修改核心资质字段，只能提交修改申请。
- 推广内容必须标注“推广”。

## 4. Risks & Roadmap

### Phased Rollout

#### MVP

- 浙江技工院校库，覆盖约 97 所学校。
- 学校列表、详情、专业筛选、城市筛选。
- 每校来源核验区。
- 10 篇家长解释型内容。
- 明确第三方免责声明。

#### v1.1

- 学校对比功能。
- 专业详情页增强。
- 费用区间筛选。
- 数据更新记录。
- 学校纠错/认领申请入口。

#### v2.0

- 家长择校问答工具。
- 个性化路径推荐。
- 开放日/招生咨询信息聚合。
- 学校展示位，但不影响自然排序。
- 数据后台和审核流。

### Technical Risks

- 官方 PDF、学校官网、公众号信息格式不统一，数据录入和更新成本较高。
- 民办学校宣传口径可能夸大，平台需要严格区分“公开信息”和“官方核验”。
- 无官方背景时，平台可信度依赖来源透明度和中立表达。
- 商业化如果过早绑定学校招生转化，可能损害家长信任。

### Product Risks

- 家长可能误以为平台具有官方背书，因此免责声明和来源标注必须明显。
- 学校可能希望修改不利信息，需要建立审核机制。
- 数据过期会迅速伤害可信度，因此每条关键数据都要显示更新时间。

## 5. Test Plan

### Functional Tests

- 用户可以从首页进入城市筛选，并看到对应城市学校列表。
- 用户可以从首页进入专业筛选，并看到开设该专业的学校。
- 用户可以打开学校详情页，并看到基础信息、专业计划、来源状态、风险提示。
- 用户可以打开内容文章，并完成正常阅读。
- 筛选条件组合后结果正确，无条件时展示全部学校。

### Data Quality Tests

- 抽样检查 20 所学校，确认名称、城市、公办/民办、专业、来源链接准确。
- 所有学校必须有 `sourceStatus` 和 `lastVerifiedAt`。
- 所有招生计划字段必须绑定 `sourceUrl` 或标记为 `待核验`。
- 民办学校必须展示费用和风险提示区域；若费用未知，明确显示“待核验”。

### UX Acceptance Tests

- 首页首屏能明确表达平台是第三方择校参考工具。
- 家长能在 3 次点击内从首页到达任一学校详情页。
- 移动端学校列表和详情页无文字遮挡、按钮溢出、筛选不可用问题。
- 页面不出现“保录取”“包就业”“官方认证”等误导性承诺。

## 6. Assumptions

- 第一版交付形态为 Web 平台。
- MVP 数据范围为浙江省技工院校库，按旧会话口径约 97 所学校。
- 商业模式在需求中轻量呈现，只明确基本边界，不展开详细付费方案。
- 平台无官方背景，因此所有产品表达以“第三方、透明、可核验、克制”为原则。
- 初期不建设复杂学校后台，学校信息修改通过人工审核或运营录入完成。
